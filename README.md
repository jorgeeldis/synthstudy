# SynthStudy

> A website where you can get a lift mood and go to the 80's at the same time!

This project is about a website that has a retro 87 ecosystem with a spotify playlist that has a bunch of cool synthwave songs, 
you can also play some sounds according in what mood are you in, from an arcade to a storm, keyboard clicks to a crackling fireplace, 
this website is specially for all students and professionals who need some music and a mood lift!
